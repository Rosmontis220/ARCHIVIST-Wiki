# 编写规范

本页面是给**通过 Pull Request 修改本 wiki 的人与 AI 代理**看的操作规范。所有条目内容以原始材料（腾讯文档、存档站、视频、GitHub Issues）为准，规范本身只约定怎么写、怎么放。

## 如何修改

1. 站点源码在 [Rosmontis220/ARCHIVIST-Wiki](https://github.com/Rosmontis220/ARCHIVIST-Wiki) 的 `docs/` 目录
2. 有写权限者直接改 `main`；无权限者 fork 后提交 Pull Request（GitHub 会自动引导）
3. AI 代理可用 GitHub API：读文件 → 改内容 → 新分支提交 → 创建 PR，PR 描述里写明改动依据与来源
4. 合并后 Pages 自动部署；提交前先本地跑一次 `python -m mkdocs build`，**构建必须零 WARNING**——断链和找不到的图片都会报出来

## 目录结构与导航

- 页面都在 `docs/` 下，按模块分目录：`档案文明/作品/xikm-hlqa-onyien`、`档案文明/作品/abandon`、`档案文明/作品/小游戏三部曲`、`Silverfish_0`、`世界`、`人物`
- 媒体统一放 `docs/media/`（按 `stamps`、`rooms`、`avatars`、`forum`、`doc1` 等子目录分类），**不随页面建图片目录**
- 新建页面必须同时在 `mkdocs.yml` 的 `nav` 里注册，否则不出现在导航
- `mkdocs.yml` 的 nav 是**全手工**的，移动页面时记得连 nav 一起改

## 页面格式

```markdown
---
tags:
  - 模块名
  - 细分标签
---

# 条目名

**条目名**是……（导语首句以粗体条目名开头，一句话说清它是什么）。

- 正文用 bullet 或小节，小节用 `##` 二级标题

## 参考来源

- [腾讯文档《XX》](https://docs.qq.com/...)（哪部分内容取自它）
```

要点：

- **H1 即条目名**，front matter 里不放 `title` 字段
- **每页末尾必须有 `## 参考来源`**，只列可公开核验的**真实标题 + URL**；不写「本人提供」「群内讨论」这类来源
- 引用原文（邮票文案、动态、游戏内文本）用 blockquote `>` 逐字保留，不改写不翻译
- 表格的列数、行数与原文档保持一致；文档里缺的格子如实留空或标注「文档注明缺失」，**不要自己补**
- 实数（隐藏文本 94 条、五枚邮票之类）以原文档统计为准

## 图片

MkDocs 把 `docs/A/B/c.md` 渲染成 `/A/B/c/`——页面 URL 比文件路径多一层，所以**目录深度 N 的页面要用 N+1 层 `../`**：

- `docs/世界/x.md`（1 层）→ `../media/...`
- `docs/Silverfish_0/邮路终端/邮件谜题.md`（2 层）→ `../../../media/...`
- `docs/档案文明/作品/xikm-hlqa-onyien/WEST.md`（3 层）→ `../../../../media/...`

写法任选：

```markdown
![说明文字](../../../media/stamps/雨前首封.png){ width=420 }
<img src="../../../media/stamps/雨前首封.png" width="420" alt="邮票一" />
```

图注用 `<figure><img .../><figcaption>...</figcaption></figure>`，长图宽图用 `width=620`，普通截图 `380~520`。图片放 `docs/media/` 对应子目录，文件名用中文描述性命名。

## 内容红线

- **禁止**任何「反编译 / 拆包 / 数据包分析 / 字节码分析」类措辞——作者明确不允许把谜题的代码分析写进 wiki
- **禁止**内部标识符（`Ro.GOALS`、`edition.properties`、`Rt.home`、`collapse` 等内部字段名）出现在正文里
- **现实与虚构分开**：本 ARG 玩家是现实中的人（AD、星幻_StarRev、dreaMRan 等），材料里的角色是虚构的；两者在同一页时用不同小节，并写清关系
- **现实身份信息打黑幕**：`<span class="heimu">本站站长</span>`（悬停/选中可见，CSS 已在 `extra.css`）。黑幕只用于现实身份类信息，剧情事实不打
- 没有材料支撑的内容宁可不写。「可能」「未证实」的推测要么放进对应页面的「待解」列表，要么留空

## 语言

- 简体中文；引号用「」，括号用（）
- 外文专名保持原文（ABANDON、RETAIN、THE EMPTY SEAT），后随中文释义
- 不写「小编」「我们」之类口吻，客观陈述

## 提交信息

一行中文简述，例如「邮件谜题表按文档原文重写：7 列，第 5 枚更正为首席代理代表「#」」。涉及结构性移动（页面换模块、改 nav）时一次提交里把所有关联引用一起改掉。
