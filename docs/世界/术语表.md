# 术语表

**术语表**收录档案文明系列材料中出现的专有名词与密钥代码。原文以调查维基 v1/v2 术语表与邮路终端邮票文案为准。

| 术语 | English | 定义 |
|---|---|---|
| 锚域 | Anchor Domain | 一套能够自洽延续的平行因果容器 |
| 锚点 | Anchor | 锚域内可被重复定位和外部寻址的固定点（[K317](锚点与投影.md) 为当前稳定锚） |
| 锚差 | Anchor Offset | 两个锚点对同一事件完成状态的差值；不是延迟，会改变「什么被认为已经发生」 |
| 回返 | Return | 现实侧材料进入人物侧因果链 |
| 渡越 | Crossing | 信息经过不可共同观察区域 |
| 回声税 | Echo Tax | 渡越时丢失的上下文 |
| 见证者坍缩 | Witness Collapse | 公开解释压掉其他可发现版本 |
| 静默互证 | Silent Corroboration | 互不接触的来源留下同一异常细节 |
| 选择噪声 | Choice Noise | 尚未被稳定记录的人的决定 |
| 预测盲点 | Prediction Blind Spot | 高层观察无法读取的未定选择 |
| 巨爆大黄昏 | Massive-Effect Great Dusk | 覆盖多个锚域并令跨维通讯完全断联的大规模效应；「巨爆」指影响范围而非物理爆炸 |
| 通讯断联 | Communication Blackout | 锚域内部继续运转，但所有跨维信号停止 |
| 盲续态 | Blind Continuity | 最后一次互相确认以后，独自走过的时间 |
| 载体 | Carrier | 能跨越锚点的介质：图片、书页、存档片段、一个人反复使用的句子 |
| W / A / O | World / Archive / Observer | 世界、归档、观察者三个会互相改动的部分 |
| MIST／雾 | MIST | 旧友[闻舟](../人物/闻舟.md)留下的四词首字母：苔藓（moss）、铁（iron）、石头（stone）、火把（torch） |
| 归档所 | ARC-00 | 保存可重新确认的状态与状态间转移记录、并保留被推翻旧版的机构 |
| ROUTE ZERO | ACTIVATION TRACE | 邮路终端第三枚邮票「未寄之门」的来源标记 |
| ROUTE ECHO | CINDER / LOTUS | 两条常驻信号：CONFRONT（密度／冲突／收束）与 Iron Lotus（回返／延伸／漂移） |
| THE EMPTY SEAT | 空席 | Silverfish_0 建立的秘密论坛；不显示时间，后被 [GOD](彼者与GOD.md) 清除索引 |
| 断联协议 | Blackout Protocol | 断联期间的行动规则：不把沉默解释成死亡、背叛、拒绝或任务完成；只追加不覆盖 |
| 计划代号 | INSIGHT FUTURE THROUGH THE FOG | 穿过迷雾洞察未来；每个词对应一类操作——观察、投射、跨越、遮蔽 |
