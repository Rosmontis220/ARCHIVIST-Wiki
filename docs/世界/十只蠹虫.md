# 十只蠹虫 / 十名外部观察者

**十只蠹虫**是存档里出现的十只异常蠹虫，每一只可能对应一名外部观察者。

观察：

- 它们没有遵循普通生成逻辑；
- 位置与**十次外部访问记录**接近；
- 在不同录像中保持了不合理的个体差异。

判断：

> 锚点无法把完整的人送进来，于是用最廉价的活体对象保存「有人看过」这件事。

后果——**清除蠹虫可能切断观察者与存档的联系，也可能反过来伤害现实中的对应者。在查明映射规则前，不得攻击。**

可推翻条件：如果杀死其中一只后外部访问记录没有任何对应变化，或者个体差异能由普通游戏机制完整解释，这个模型就应废弃。

蠹虫也是 [SILVERFISH_0](../Silverfish_0/index.md) 名字的两个来源之一（另一个是「在纸张和档案缝隙里存活的东西」）。
