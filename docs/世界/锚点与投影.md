# 锚点与投影

**锚点**是相对独立的世界范围：每个锚点有自己的事件顺序、人物和结果。

- 跨锚点并非完全隔绝：文字、记录、程序，甚至人的痕迹，都有机会跨越；
- 跨锚点的信息会破坏锚点内部的因果稳定，所以系统会**限制、筛选或重新翻译**它——跨锚点看起来像「穿越」；
- 同一件事可能留下多个版本：一份材料记录原始事件，另一份是后来重演或整理的版本；它们共享固定细节，也会在人物、地点和时间上对不上；
- 投影不是副本：**ABANDON 三端**正是同一来源对象的三个投影（FORM / ORDER / WITNESS），「差异要被保留，而不是被纠正」。

锚点可以被破坏。
