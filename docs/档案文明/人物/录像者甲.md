# 录像者甲（RECORDER_A）

**旧 Minecraft 存档的玩家；西侧异常的发现者；B 站首集【WEST主人公。**

- 中文使用者，年纪不大，对旧存档有真实情感依赖；
- 他的优势不是知识，而是**能记住基地原来的样子**——换成任何第一次进入该世界的人，西侧接缝都会被当成正常地形；
- 重返旧存档后，发现基地西侧与记忆不符：河流被截断、树林出现重复结构、部分建筑像被另一份存档错误覆盖；
- 旧友[闻舟](闻舟.md)多次阻止他过河；他无视警告继续调查。

> 他不是侦探。他只是第一个没有把异常当成模组问题的人。

## 可靠性

SILVERFISH_0 在调查维基中把他作为一手材料的主角，并且：

**信任的部分**：对物品摆放和路线的即时反应；不知道答案时的停顿；面对旧友阻止时的犹豫；前后录像中重复出现的操作习惯。

**不信任的部分**：他太容易把「熟悉」当成「安全」。如果某种东西能够复制存档，也能复制朋友的语气。录像者甲知道得越少，越可能成为理想载体。

没有发现他主动伪造异常的证据。但「不是造假者」与「叙述可靠」是两回事。
