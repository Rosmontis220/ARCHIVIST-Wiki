# Mac Trang Phat

**WITNESS 端 DAT 返航记录中的名字。**

ABANDON 三端各产出一份 DAT 文件。WITNESS（Android 端）的 DAT 文件全文为：

```
EXTERNAL RETURN RECORD 0001
NAME RETAINED: Mac Trang Phat
IDENTIFIER RETAINED: 1809982305
EVENT: WEST RETURN
STATUS: ACCEPTED
```

疑点：

- 这份记录在事件栏写的是 **WEST RETURN**，而[闻舟](闻舟.md)在 ABANDON 发布视频简介中作为 `SOURCE SUBJECT: WENZHOU` 出现；
- 彼者在[阈限对话](彼者.md)中说，神不传输语言，只传输意义——「汝之心智，会为它披上自己能够承受的言语」；如果连语言都会随听者变化，名字是否也会？
- 1809982305 的格式像即时通讯账号标识，目前**未确认**其指向。

Mac Trang Phat 与闻舟是同一人在另一段记录里的名字、还是另一名档案员，暂无定论。
