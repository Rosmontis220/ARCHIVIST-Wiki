# K317

**一个锚点——目前稳定的固定点代号，而不是一个人名。**

- K317 是 SILVERFISH_0 在调查维基《锚点假说》中记下的固定点：哔哩哔哩与抖音上的两条公开记录让它容易被反复定位——一边保存较完整的叙述，一边保存更快、更短的响应；
- [XIKM](XIKM.md) 的简介说「我的名字隐藏在 K317 的简介里」，使 K317 同时也是另一重身份的藏身处；
- **平台不是锚点的制造者，只是目前可见的定位标记**——这也是不建议把全部材料迁移到同一网站的原因。

与 [VHQ-4K/19](VHQ-4K-19.md) 一样，K317 目前更像系统分配的定位代号；把它直接当成人名会带来很多解释不通的地方。第二个稳定锚点的位置仍然未解。
