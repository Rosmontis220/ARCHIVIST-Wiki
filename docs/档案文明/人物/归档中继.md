# 归档中继（ARCHIVE_RELAY）

**归档系统的中继；「回返」的确认方。**

- 现实参与者取得 `west_fragment.png`／西侧残片，按要求保留原件并交给归档中继后，中继返回了**有效登记**——至少在文件层，回返（Return）已经成立；
- 这是第一次证明方向可以反过来：多数异常只把信息从人物世界送到现实侧，西侧残片让现实参与者的选择能给人物世界增加一个此前不存在的原因。

归档中继被 SILVERFISH_0 明确列为「我可以不代表」的一方（另一位是[录像者甲](录像者甲.md)）：

> 中继不可能为一个纯粹的收件动作使用「回返」这个词。

**实际管理者身份未明**——调查维基的「缺页索引」把它列为第一条。
