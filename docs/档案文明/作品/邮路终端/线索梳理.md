# 线索梳理

> 这一栏只是把目前能对上的线索先拼起来，肯定有错。材料的发布时间很可能不等于事情发生的顺序，账号、角色和文件里的名字也未必一一对应。

## 锚点与投影

- 这个故事里的世界不止一个。每个世界都有自己的事件顺序、人物和结果，材料里把这种相对独立的范围叫作「锚点」；
- 不同锚点之间并非完全隔绝：文字、记录、程序，甚至人的痕迹，都有机会跨越；
- 一个锚点内部应该有相对稳定的因果关系；跨锚点的信息会破坏这种稳定，所以系统会限制、筛选或重新翻译它——跨锚点看起来像「穿越」；
- 同一件事可能留下多个版本；锚点可以被破坏。

## 时间顺序

- 材料的发布顺序不能直接当作故事时间：后发布的文件可能记录更早的事，早期视频也可能经过重演、剪辑或重新整理。

## ABANDON 的作用

- ABANDON 表面上是游戏或程序，它至少承担了存放线索、验证操作和展示某段记录的功能；
- 玩家在里面完成的操作，会把分散的内容重新拼成一个能被观察的版本；
- 三份 DAT、macOS 端的处理以及 RETAIN、THRESHOLD 等内容，像是一条人为设计的读取路径；它可能只记录玩家选择，也可能把选择写回某个锚点。
