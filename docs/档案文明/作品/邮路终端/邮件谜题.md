## 投递准则

> 找到一个仍在工作的现实层投递口。邮筒、信箱、邮局窗口都被接受。
> 在现场留下一张白纸，并拍下它与投递口同时存在的照片。
> 不要把任何东西真正投入其中。
> 将照片作为附件，投递到虚拟层的投递口。
> 如果这次投递被接受，你会收到一段 RETURN。
> 把 RETURN 带回邮路终端。
>
> ——投递不要求寄件人。
