# RETAIN 与 THRESHOLD

三端 DAT 齐备后，NPC 发来新游戏 **RETAIN**（仓库 archive/retain/，浏览器可直接玩）。在 macOS 端可将三个 DAT 文件融合，进入新游戏 **THRESHOLD**。

## THRESHOLD

- 玩法：走迷宫，共 **6 关**，路线图形为 **231705**
- 全部六关后进入密码输入页，提示 `THE PASSAGE IN THE BIBLE.`
- 按之前的解密方法解图片得 `THEY THAT GO DOWN TO THE SEA IN SHIPS`（《圣经·诗篇 107:23》），保留数字 **10723**
- 路线图形 + 圣经线索 = 终密码 **23170510723**

## 通关后

输入密码后得到[闻舟](../../../人物/闻舟.md)与[彼者](../../../世界/彼者与GOD.md)的全英文对话（即《FULL DIALOGUE：UNSET ENTER》）与返航邮件模板：

```
COMPOSITE OBSERVER RETURN
DAT_KEY: （前面 dat 文件中的 key）
FINAL PASSWORD: 23170510723
TEAM NAME: [NAME OR NONE]
TEAM INTENT: ENTER（DECLINE）
MEMBER COUNT: [NUMBER]
MEMBERS 01 / NAME TO BE RETAINED: [NAME OR HANDLE] / INTENT: ENTER（DECLINE）
        …（按需增删行）
DECLARATION
Every listed member has seen the team decision above and agrees to have that
decision returned as part of this ARG record.
END RETURN
```

主题：**WE WILL (NOT) CROSS**——对应对话末尾的选择：「尔等解开此记录之人：尔等愿前往档案馆，还是留在如今这片海岸？」
