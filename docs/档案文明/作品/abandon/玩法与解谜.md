# ABANDON 玩法与解谜

三端各 v0.0.0：**FORM**（macOS）、**ORDER**（Windows）、**WITNESS**（Android）。无 macOS 可用 Windows 文件夹内的 html 直接游玩。

## 三层流程

1. **第一层**：macOS 记忆排序 / Windows 比较大小 / Android 兔子洞。三端各得一个 **A1 密钥**。
2. **第二层**：左侧交互后，输入除本端外任意一端的 A1 密钥，并按顺序与四个图案交互（要求三端一致），得三个 **A2 密钥**。
3. **第三层**：输入除本端外两端的两个 A2 密钥，确定后显示三句话——对应端文本为白色，另外两端为灰色：

> FORM WAS NEVER COMPLETE.
> ORDER WAS NEVER LINEAR.
> WITNESS WAS NEVER OUTSIDE.

随后得到三个端的 [DAT 文件](DAT文本.md)。

**隐藏第四关**：由「FORM WAS NEVER COMPLETE」可知 macOS 端解谜尚未结束——选关界面输入 4 进入隐藏关。**隐藏关密码尚未解出。**

:material-gamepad: 得到三个 DAT 后，NPC 发来新游戏 **RETAIN** 的下载链接，见 [RETAIN 与 THRESHOLD](RETAIN与THRESHOLD.md)。
