# 世界与流程

## 四座档案馆

顺序固定，任务在四座自定义维度中进行：

| 顺序 | 名称 | 副标题 | 任务数 |
|---|---|---|---|
| 1 | 档案馆 | 记录在此保留 | 21（任务 0–20） |
| 2 | 锚点枢纽 | 所有航路交汇于此 | 21（任务 21–41） |
| 3 | 归档所 | 材料进入主索引 | 21（任务 42–62） |
| 4 | 复核室 | 执行最后的复核 | 1（任务 63） |

四维度共用一种类型：无天光、固定正午（6000）、无降水、无怪物自然生成、无床/重生锚点功能、末地风格天空。地表由自定义 `shelves` 生成器构建（书墙结构 / 环网 / 归档匣 / 复核长厅）。

## 核心循环

接入（右键编目册查看任务）→ 到站交任务（右键磁石）→ 任务逐个推进 → 阶段满 → 交接区右键**越界罗盘**进入下一馆 → 复核室十笼 → 最终执行 → 回执 → 存档锁定。

每馆在编目站（原版磁石锚定）完成任务，终点是**交接区**。推进条件：当前任务编号 ≥ 该馆终点（21/42/63/64），且玩家在交接区 8 格内。不满足时提示「索引校准尚未完成。」或「本阶段尚有 N 项未完成。」；最后一馆再使用提示「此处没有下一层。」

任务完成奖励：每任务 **16 个骨粉**。
