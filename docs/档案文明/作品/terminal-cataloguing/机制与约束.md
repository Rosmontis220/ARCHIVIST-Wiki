# 机制与约束

## 磁石交互

模组核心，三种用法：

- **中央补给区磁石**：右键打开任务面板（手持交易材料时顺带兑换）；**蹲下右键**补给（60 秒冷却）
- **各编目站磁石**：右键提交 / 推进任务
- **复核室笼前磁石**：右键开笼

## 玩家版约束（`edition.properties` = `creator=false`）

- **仅生存模式**：登录时检测游戏模式，非生存即封禁（「投影访问已撤销。」+ 锚点封禁锁文件）
- **死亡保护**：保留台记录返回位置，普通死亡后返回此处；死亡消息「该锚点已损坏。」
- **存档锁定后**：再次登录直接踢出（破损→「该锚点已损坏。」 / 封禁→「投影访问已撤销。」）
- 开局包：石镐、石斧、熟牛肉×16、小麦种子×8、甘蔗×8、橡树树苗×4、骨粉×16、水桶 + 编目册 + 越界罗盘（仅此一件模组物品）

模组内自带创作者控制台，被该开关关闭（翻为 true 可解锁，仅测试用；创作者版另有 10 个传送点，其中 4 个借用任务地名）。

## 黄雾

客户端分层浓雾（浓度 / 色调按馆分层、随时间动画），是渲染而非机制；雾晶为合成产物，无采集来源。
