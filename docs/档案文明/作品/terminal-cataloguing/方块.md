# 方块（3 件）

| 方块 | 合成 | 功能 |
|---|---|---|
| 保留台 retention_plinth | 铁锭 + 保留印 | 右键记录死亡返回位置（播报「位置已记录。」）；普通死亡后返回此处 |
| 阅读灯 reading_lamp | 玻璃 + 灰烬灯 | 右键获得 2 分钟夜视 |
| 索引压机 index_press | 橡木板 + 索引碎片 | 右键消耗 8 张纸产出 2 记忆纤维（材料不足提示「需要八张纸。」） |
