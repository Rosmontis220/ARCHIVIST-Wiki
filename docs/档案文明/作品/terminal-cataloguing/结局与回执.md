# 结局与回执

任务 63「最终编目」在数据上为 FINAL + 空气×10 + 无站点——无交付物，完成条件就是十笼：

1. 进入复核室（第四馆）后，十笼蠹虫就位
2. 按一至十的顺序右键笼前磁石开启铁笼，**亲手击杀蠹虫**
3. 十只全部死亡：任务直接设为 64，塌缩序列开始
4. 塌缩第 620 tick：播报「十处执行完成。」并公示**回执**（聊天栏）
5. 塌缩第 700 tick：玩家版**永久锁定存档**（写入锚点锁文件，全体在线玩家收到回执广播）；创作者版则重置（塌缩清零、笼复位、玩家送回出生点）并提示「结局预演结束。创作者存档已保留，可重新测试。」

**回执公式**：`RETURN-` + SHA-256(服务器身份 + 笼位图 + 有效游戏刻) 十六进制前 24 位（大写）

> 十只蠹虫对应十名外部观察者。参见 [十只蠹虫](../../../世界/十只蠹虫.md)。
