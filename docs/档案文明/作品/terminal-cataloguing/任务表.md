# 64 任务权威表

六类任务：**VISIT 抵达**（到站右键磁石提交观察）、**OFFER 交付**（携带并交付 N 个指定物品）、**BUILD 放置**（磁石周围 24 格内放置 N 个指定方块）、**TRIAL 试炼**（右键启动，亲手击败 N 个残像，每波 ≤6）、**WAIT 生存**（磁石周围 24 格内连续生存 N 秒，离开或死亡重新计时）、**FINAL 最终**（复核室十笼）。

站点名仅六个有官方名称：**边阶入口 / 保留营地 / 残像试炼场 / 黄雾观测台 / 无声编目室 / 最终投影室**；其余站点无官方名称。
