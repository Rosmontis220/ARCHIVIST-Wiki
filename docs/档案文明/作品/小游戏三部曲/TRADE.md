# TRADE（卡牌）

- 卡牌克制：**红＞黄＞绿＞黑＞红**；移除一个颜色后克制链去掉该颜色并继续延续；
- 克制时数值 **+2**；同色相邻时数值 **+1**；
- 赢下所有四局游戏后，拿起背后门上的枪击杀对手，进入真结局。
