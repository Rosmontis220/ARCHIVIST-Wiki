# REVIEW（复核）

登录 ACCESS KEY **ARG-#REVIEW-73104**；129 可解锁中文。四关，每关流程：

| 元素 | 位置 | 内容 |
|---|---|---|
| 推箱子 | 下层左上 | 把两个箱子推到两个槽位上 |
| 线路操作台 | 下层上方 | 旋转 9 节管道，把线路从左连到右下 |
| 投影谜题 | 中层右方 | 按 E 推配重；折叠 2D 状态黄色部分可走，展开 3D 状态绿色部分可走，转角处按 E 激活中继并按 TAB 切换视角（存在 BUG：上中层时需保证为展开状态，否则配重不会生成） |
| 复核台 | 下层下方 | 查阅两处见证后提交结论 |
| 留存材料 | 上层上方 | 复核通过后才能拿，拿到后去回送门交付 |
| 回送门 | 下层右方 | 提交留存材料并进入下一关 |
