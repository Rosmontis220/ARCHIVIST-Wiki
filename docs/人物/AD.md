# AD

**B 站首集【WEST】的主人公。**

- 他得到了一份台本，并配合完成了演出；
- 在设定中，他是那座旧 Minecraft 存档的玩家：中文使用者，年纪不大，对旧存档有真实情感依赖；
- 他的优势不是知识，而是**能记住基地原来的样子**——换成任何第一次进入该世界的人，西侧接缝都会被当成正常地形；
- 重返旧存档后，发现基地西侧与记忆不符：河流被截断、树林出现重复结构、部分建筑像被另一份存档错误覆盖；
- 旧友[闻舟](闻舟.md)多次阻止他过河。
