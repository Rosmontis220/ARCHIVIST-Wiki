# ADsurfb0ard

**ADsurfb0ard**（简称 **AD**）是本 ARG 的玩家之一：中文使用者，秘密论坛 **THE EMPTY SEAT** 的成员，论坛账号即 ADsurfb0ard。B 站首集【WEST】中，他拿到一份台本并配合完成了演出。

## 录像者甲（虚构角色）

「录像者甲」是调查维基对【WEST】视频主人公的临时编号——虚构角色，与 AD 本人不是同一人。在设定中：

- 他是那座旧 Minecraft 存档的玩家：中文使用者，年纪不大，对旧存档有真实情感依赖；
- 重返旧存档后，发现基地西侧与记忆不符：河流被截断、树林出现重复结构、部分建筑像被另一份存档错误覆盖；旧友[闻舟](闻舟.md)多次阻止他过河；
- 视频冷开场揭示了一段「之后」的片段：录像者甲准备删除 `r.-1.0.mca.lock` 时，闻舟在微信问「你已经发出去了？」「那现在删什么。」画面在删除前切断。
