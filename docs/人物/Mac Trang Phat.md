# Mac Trang Phat

**Mac Trang Phat**是 ABANDON WITNESS 端 DAT 记录《EXTERNAL RETURN RECORD 0001》中的留名者，完成过一次状态 **ACCEPTED** 的 WEST RETURN。

ABANDON 三端各产出一份 DAT 文件。WITNESS（Android 端）的 DAT 文件全文为：

```
EXTERNAL RETURN RECORD 0001
NAME RETAINED: Mac Trang Phat
IDENTIFIER RETAINED: 1809982305
EVENT: WEST RETURN
STATUS: ACCEPTED
```

已知：

- 他完成了一次 **WEST RETURN**，记录状态为 **ACCEPTED**；
- IDENTIFIER 1809982305 的格式像即时通讯账号标识，目前**未确认**其指向；
- 除此之外材料中再没有出现过这个名字，也没有他的行为记录。
