# 星幻_StarRev

**星幻_StarRev**是本 ARG 的玩家之一，<span class="heimu">本 wiki 的建立者与维护者，本站站长</span>。

- ID 为其 QQ 用户名；签名出自《废墟图书馆》Library of Ruina：「我纵茕茕孑立，难避漫漫长夜。然长夜终尽，天将启明……惟以平旦之孤星，何胜东方之既白。」
- 在剧情中是邮路终端名义上的管理员：从 v2 起邮路终端与他有关，v1 阶段他只是在模板碎片里发出了自己的 QQ 号；
- 邮路终端 v1 模板碎片中受赠一枚邮票，第二枚邮票以其命名；
- <span class="heimu">建立并维护本 wiki，整理 SILVERFISH_0 相关材料的存档</span>。
