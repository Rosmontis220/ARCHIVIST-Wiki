# 入门

第一次来到这个 wiki 的话，从这里开始。

## 这是什么

本站是围绕两个相互关联的项目建立的知识库：

- **档案文明**：SILVERFISH_0 发布的解谜系列（B 站视频【WEST】【fragment】【ABANDON】、三端解谜游戏 ABANDON、小游戏三部曲）
- **Silverfish_0**：以 GitHub 仓库为「据点」进行邮件互动解谜（邮路终端）与档案发布的一方

材料混合了现实层的账号、存档与虚构层的剧情，两者处处对应又处处错位——这是阅读时需要注意的基本结构。

## 从哪里看起

按发布顺序体验原作，再回来看 wiki 对应条目：

1. [【WEST】](档案文明/作品/xikm-hlqa-onyien/WEST.md)：旧 Minecraft 存档西侧的异常
2. [【fragment】](档案文明/作品/xikm-hlqa-onyien/fragment.md)：音频与水杯里的线索
3. [【ABANDON】](档案文明/作品/abandon/index.md)：三端解谜游戏（FORM / ORDER / WITNESS）
4. [小游戏三部曲](档案文明/作品/小游戏三部曲/index.md)：GROUP / TRADE / REVIEW，含 94 条隐藏文本
5. [邮路终端](Silverfish_0/邮路终端/index.md)：以 GitHub Issues 为投递口的邮件解谜

只想快速建立概念，可以先读[锚点与投影](世界/锚点与投影.md)与[归档中继](世界/归档中继.md)。

## 参与编辑

本 wiki 依靠 Pull Request 协作：

- **改现有页**：每页右上角「编辑此页」铅笔按钮
- **新建整页**：在 GitHub 的 [docs 目录](https://github.com/Rosmontis220/ARCHIVIST-Wiki/new/main/docs/)点 **Add file → Create new file**

两者都自动走 PR 流程，合并后上线。动笔前请先读[编写规范](编写规范.md)。
